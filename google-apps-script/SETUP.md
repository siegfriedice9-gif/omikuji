# 法楽寺おみくじ：Googleスプレッドシートによる回数集計（検証版）

## 現在の実装内容
- **集計するもの**：おみくじの結果が表示された回数。ページ閲覧・管理者モードの番号移動は数えません。
- **保存先**：Googleスプレッドシート（非公開）。日時・年月・年・ランダムなイベントIDを保存します。
- **管理方法**：管理者モードに統計へのリンクが出ます。リンク先のGoogleスプレッドシートで「累計／当月／当年」を確認します。
- **正式サイトへの影響**：なし。これは個人用 `siegfriedice9-gif/omikuji` の検証ブランチにのみ実装しています。
- **現在の動作**：接続URLが未設定なら記録は始まりません。設定後に試験できます。過去のブラウザ内カウントは引き継ぎません。

## 準備するもの
1. Googleアカウント（試験用は個人アカウントでも可。本番用の集計シートは法楽寺が管理するアカウント推奨）
2. [Googleスプレッドシート](https://sheets.google.com/) の新しい空ファイル
3. このリポジトリの `google-apps-script/Code.gs` 、`analytics-config.js`

## 1. Googleスプレッドシートを作成
1. Googleスプレッドシートで新規ファイルを作り、例：`法楽寺おみくじ_検証用集計` と命名。
2. **共有** → **一般的なアクセス** → **制限付き** に設定。共有対象は管理者のGoogleアカウントのみにします。
3. **ファイル** → **設定** → **タイムゾーン** を `(GMT+09:00) Tokyo` に設定。集計の月・年の境界を日本時間に揃えます。
4. スプレッドシートのURLを控えておきます。**URLを公開コードに置いても閲覧権限は付与されません**が、URL自体は閲覧可能なので取り扱いには注意してください。

## 2. Apps Scriptを作成
1. スプレッドシートの **拡張機能** → **Apps Script** を開く。
2. エディタの `Code.gs` を、このリポジトリの `google-apps-script/Code.gs` の内容で置き換え、保存。
3. 上部の関数選択で `initializeOmikujiAnalytics` を選び **実行**。初回のGoogle権限確認は自分のアカウントで承認します。
4. スプレッドシートに `events` と `summary` ができたことを確認。`summary` は累計、当月、当年が最初は0回です。

## 3. 記録用Webアプリをデプロイ
1. Apps Script の **デプロイ** → **新しいデプロイ** → 歯車の **ウェブアプリ** を選ぶ。
2. **次のユーザーとして実行**：**自分**。
3. **アクセスできるユーザー**：**全員（匿名を含む）**。一般の参拝者がGoogleログインなしで記録するために必要です。
4. **デプロイ**を押して承認。発行される `https://script.google.com/macros/s/.../exec` URLを控えます。
5. 一般公開されるのは記録受付URLのみです。統計取得用のAPIは提供していません。集計シートの共有設定は「制限付き」のまま維持してください。

## 4. 検証版の接続設定
`analytics-config.js` を検証ブランチ上で次のように設定します。

```js
window.OMIKUJI_ANALYTICS_CONFIG = Object.freeze({
  collectionUrl: 'https://script.google.com/macros/s/発行されたID/exec',
  privateSheetUrl: 'https://docs.google.com/spreadsheets/d/スプレッドシートID/edit'
});
```

- **URLはコード上で公開されます。** パスワード、GoogleのAPIキー、認証トークンは絶対に入力しないでください。
- URLはチャットに貼らず、ご自身のGoogle/GitHub画面上で設定しても構いません。
- このブランチはまだGitHub Pagesには反映されません。検証用の公開手段またはローカルWebサーバーを別途準備してから動作確認します。

## 5. 動作確認
1. 通常モードでページを表示するだけでは増えない。
2. 通常モードでおみくじを1回引き、結果の運勢が画面に出た後、シート `events` に新しい1行が追加される。
3. `summary` の累計・当月・当年が1ずつ増える。
4. 管理者モードを開き、統計リンクが表示される。管理者のGoogleアカウントではリンク先を開けるが、権限のないGoogleアカウントではシートを開けない。
5. 管理者モードの「前へ／次へ」で数は増えない。表示だけや再読み込みでも増えない。
6. 異なる端末で引いた場合にも同じシートの数が増える。
7. 新しい月・年の境界を越えたとき、当月・当年のみ期間に応じて切り替わり累計は維持される。

## 実装上の留意点（重要）
- GitHub Pagesの静的コードから匿名POSTを受ける方式です。**不正送信を完全に防ぐことはできず、厳格な監査用カウントには向きません**。またオフライン・通信遮断・Google側障害・Apps Scriptの利用上限では記録漏れが起こり得ます。
- 一度だけ数える処理は同一ページ内の重複イベントに対応しています。Apps Script側もイベントID重複を検査しますが、悪意ある送信者は新しいIDを生成できるため完全な不正対策ではありません。
- ブラウザからはGoogle側での保存成否を直接確認できません。**検証にはGoogleシートの追記とApps Scriptの実行履歴を確認してください**。
- 管理者モード内には**統計リンクを表示する暫定方式**です。数値をおみくじ画面に直接表示する方式には、別途Googleアカウントの認証付き表示サーバーが必要です。
- 検証用と本番用はシート・Apps Script URLを分離してください。本番公開前に法楽寺の管理者へシート共有権限を引き継ぎます。
- Apps Scriptの無料枠、同時実行数、実行時間には上限があります。実際の利用量と実行ログを確認しながら運用します。
